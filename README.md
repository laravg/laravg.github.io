# Lara Vázquez González

Source code of my personal website: **[laravg.github.io](https://laravg.github.io)**

I am a bioinformatics researcher with a PhD in Information Technology Research from the University of Santiago de Compostela (USC). My work focuses on microbiome data analysis and machine learning for health.

## Contents

- **About**: background, skills and featured projects
- **Publications**: peer-reviewed articles and conference papers
- **Projects**: research software, databases and pipelines I have developed
- **Repositories**: links to my code on GitHub and GitLab
- **CV**: online CV and downloadable PDF

## Running locally

The site is built with [Jekyll](https://jekyllrb.com/). To preview it with Docker:

```bash
docker compose up
```

Then open [http://localhost:8080](http://localhost:8080).
